# Contributing to PORTO

Makasih udah tertarik kontribusi ke **PORTO**! Ikuti panduan berikut biar prosesnya lancar.

## Getting Started
1. Fork & clone repo ini
   ```bash
   git clone https://github.com/mchann/porto.git
   cd porto
   ```
2. Install dependencies
   ```bash
   npm install
   ```
3. Buat branch baru dari `main`
   ```bash
   git checkout -b feature/nama-fitur
   ```

## Commit Convention
Pakai [Conventional Commits](https://www.conventionalcommits.org/):
- `feat: ...` fitur baru
- `fix: ...` perbaikan bug
- `chore: ...` perubahan non-fitur (config, deps, dll)
- `docs: ...` perubahan dokumentasi

## Pull Request
1. Pastikan branch kamu up to date dengan `main`
2. Jelaskan perubahan dengan jelas di deskripsi PR
3. Tandai issue terkait (mis. `Closes #12`)
4. Tunggu review dari maintainer sebelum merge

## Code Style
- Ikuti konvensi kode yang sudah ada di project
- Jalankan lint/test dulu sebelum push (kalau tersedia)

## Reporting Issues
Nemu bug atau punya ide fitur? Buka issue baru dan sertakan:
- Deskripsi masalah/fitur
- Langkah reproduksi (kalau bug)
- Screenshot/context tambahan (kalau ada)
